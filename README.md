In my free time, I’ve been doing a bit of AI assisted coding, currently I’m building Pluteus, a custom toy blockchain designed and implemented from the ground up in Rust. It is specifically architected to compile down to WebAssembly (Wasm) with the ultimate goal of running natively as a distributed workload native on Kubernetes.
For the execution layer, the network utilizes Starlark to run smart contracts. Starlark provides a highly deterministic, Python-like environment that is perfect for enforcing strict state transitions on a blockchain. It completely sidesteps the bloat and unpredictability of heavier virtual machines, allowing for secure, sandboxed execution.
Writing the core in Rust means its built for performance and memory-safety is guaranteed. The consensus mechanism is a simplified version of Federated Byzantine Agreement (FBA), binary serialisation is optimised using rkyv, to ensure the chain operates efficiently. My goal was to strip away the abstractions of blockchain and build something cool powered by Webassembly as a fault tolerant system that actually works at scale.
